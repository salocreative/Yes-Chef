# Salo x Yes Chef Studio: concept pack

A one-page concept pack made by Salo for Yes Chef Studio: enhanced brand, brand kit, token switch, credentials deck concept, homepage UX audit and ways to work together.

Static site. No build step, no dependencies. Fonts load from Google Fonts.

## Run locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000. Open it through a server, not by double-clicking `index.html`, so the images load correctly into the heat effects.

## Files

- `index.html`: the page
- `brand.css`: Yes Chef enhanced tokens (colour, type, ticket, buttons)
- `tear.css`: torn-paper edge masks
- `pack.css`: layout and section styles
- `fx.js`: shared motion (heat fields, reveals, tilt, count-ups, scroll pins)
- `pack.js`: page interactions (slider, ticket, switch, deck, audit)
- `audit-data.js`: UX audit notes and scores
- `assets/`: logos, case-study crops, project screenshots, audit captures, one photo
